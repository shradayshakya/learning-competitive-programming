C ++ basics

Input / Output
* #include<iostream> => Header for stream
* Use #include <bin/stdc++.h> to import all libraries (not recommended for production)

Namespace
	* using namespace std
	* istead of std::cout, you'll just write cout 

Output/Input
	* cout => standard output stream
	* endl => end of the line (\n)
	* cin => standard input stream ( space or \n)
	* getLine => standard input stream that gets a line

Insertion Operator ( << ) 
	* inserts data in the output stream 
	* chaining multiple insertion operators together 

Extraction Operator ( >> )
	* takes dat afrom the input stream
	* chaining multiple extraction variables (separated by white space)

Basic data types 
	* char (1 byte)
	* short (2 byte)
	* int (if decimal number is assigned then the decimal points are truncated) (4)
	* float (4 bytes)
	* double (8 bytes)
	* long double (12 or 16 bytes)
	* bool 
		* (output is either 1 or 0)
		* everything except 0 is truncated
		* 1 byte
	* long int (long) (4 or 8 bytes)
	* long long int (long long) (8 bytes)

Arithmetic Operators
	* +
	* -
	* *
	* /
	* %
	* ++variable
	* variable++
	* --variable
	* variable--
	* variable+2 (applies for - * /)

Relational Operatos
	* ==
	* !=
	* >
	* <
	* >=
	* <=

Character
